شکاف‌های فعلی معماری (وضعیت واقعی کد، نه اسناد)

Gateway هنوز وارد مدار نیست. فرانت مستقیم به PHP وصل است؛ Kong فقط ۴ مسیر دارد (auth/blogs/news→PHP و projects→Django)، مسیر پیش‌فرض/catch-all به PHP ندارد، پورتی روی هاست publish نمی‌کند، TLS واقعی و پلاگین‌های CORS/rate-limit/observability ندارد و کانفیگ در ایمیج پخته می‌شود (تغییر مسیر = rebuild). اولین قدم عملی: catch-all→PHP + انتشار پورت + TLS + اتصال فرانت به Gateway.
Django در حد اسکلت است. روی main فقط /health و /me (پل توکن legacy)؛ کار JWT/User روی برنچ issue-9 مانده؛ production.py خالی و Dockerfile کپی‌شده از پروژه‌ی دیگر است. تا پایداری این‌ها، هیچ مسیری نباید به Django سوییچ شود.
Realtime هنوز طراحی اجرایی ندارد. پیام‌رسان محصول به WebSocket/SSE + Redis نیاز دارد (تسک B14.4)؛ جای آن در این نقشه رزرو شده است.
امنیتی: ریموت گیتِ چند ریپو حاوی توکن oauth2 در URL است — چرخاندن توکن‌ها فوری است.
